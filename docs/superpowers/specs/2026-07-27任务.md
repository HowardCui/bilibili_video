# 热门榜趋势与梗分析流水线


每六小时按可配置分区采集热门视频及播放、点赞、投币等指标。

持续保存快照，计算播放量、排名和互动量的变化速度。

获取弹幕并检测时间轴上的多个峰值，再关联对应字幕内容。

跨视频、跨时间聚类高频表达，输出分区级或全站 meme/梗趋势。

## 架构

    ranking_collector/
    ├── __init__.py
    ├── config.py       # 分区及调度配置
    ├── client.py       # 调用 Bilibili 排行榜接口
    ├── models.py       # 榜单快照、视频指标数据结构
    ├── repository.py   # SQLite 建表、写入和历史查询
    ├── service.py      # 单次采集与播放量变化计算
    ├── scheduler.py    # 00/06/12/18 点调度
    └── main.py         # 独立启动入口
