# 本地综合网站实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `127.0.0.1:8000` 提供一个参考目标图片视觉风格的本地综合网站，包含只读排行榜和可持久化、可恢复、可重试的视频总结流程。

**Architecture:** `web_ui/` 是 React + Vite + Tailwind CSS + TypeScript 单页应用，开发时代理 `/api`，构建后由 FastAPI 提供静态资源。`web_app/` 提供稳定 JSON Schema、排行榜只读查询和 SQLite 总结任务队列；后台线程复用现有视频处理与总结流水线，服务启动时恢复未完成任务。

**Tech Stack:** Python 3.12/3.13、FastAPI、Uvicorn、SQLite、pytest、React、Vite、TypeScript、Tailwind CSS、Vitest、Testing Library、Playwright。

## Global Constraints

- FastAPI 正式启动必须绑定 `127.0.0.1:8000`，不得默认绑定 `0.0.0.0`。
- 前端代码、前端测试、前端构建配置和网页设计文档全部位于 `web_ui/`。
- Python 后端位于 `web_app/`；现有业务模块不得引入 React 或 HTTP 依赖。
- Python 类和 TypeScript 类均不使用装饰器；React 仅使用函数组件。
- Python、TypeScript 和浏览器测试只写普通测试函数，不使用测试类。
- 排行榜网页只读，不提供触发采集或控制调度器的接口。
- Cookie、API Key、堆栈、模型原始错误和本地绝对路径不得进入 HTTP 响应。
- 同一 BV 号最多一个活跃总结任务；成功结果默认复用。
- 启动时自动重新排队 `PENDING` 和遗留 `PROCESSING` 任务；失败任务支持手动重试。
- 动画必须支持 `prefers-reduced-motion`。
- 保持现有排行榜 `--once`、`--schedule` 和测试行为不变。
